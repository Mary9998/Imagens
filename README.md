# 🔍 Pixabay Gallery

Galeria de imagens desenvolvida com **JavaScript puro (Vanilla JS)**, consumindo a **API do Pixabay**. Permite buscar imagens por palavra-chave, navegar entre páginas de resultados e visualizar tags, curtidas e comentários de cada imagem.

https://github.com/user-attachments/assets/3d402611-5d9c-455c-9edb-37f2c39e509a


## ✨ Funcionalidades

- Busca de imagens por termo (basta digitar e pressionar `Enter`)
- Paginação com botões de próxima/anterior e navegação direta por número da página
- Exibição de tags clicáveis para nova busca
- Exibição de likes e comentários de cada imagem
- Link direto para a página original da imagem no Pixabay

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript (ES6+, async/await, fetch API)
- [Pixabay API](https://pixabay.com/api/docs/)
- Font Awesome (ícones)

## 📦 Como executar

1. Clone este repositório
   ```bash
   git clone https://github.com/Mary9998/seu-repositorio.git
   ```
2. Abra o arquivo `index.html` no navegador (ou use a extensão **Live Server** do VS Code)

## 🔑 API Key

O projeto utiliza uma chave de API do Pixabay. Para rodar com sua própria chave, crie uma conta gratuita em [pixabay.com/api](https://pixabay.com/api/docs/) e substitua o valor da constante `key` no arquivo `pixabay.js`.
